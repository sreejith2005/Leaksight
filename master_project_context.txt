MASTER PROJECT CONTEXT FILE

LeakSight û Enterprise Commercial Intelligence Suite
Master Context
LeakSight is an enterprise financial control software suite designed to detect commercial and financial risk in vendor transactions.
The system is not:
an ERP
a payment processor
a procurement workflow
a predictive analytics tool
The system is:
a post-facto verification engine
a financial control layer
an audit-grade evidence generator 
LeakSight v1 - PRD

Core Philosophy
The product is built around three truths:
Commercial Truth û What was contractually agreed
Operational Truth û What was ordered/received
Financial Truth û What was invoiced and paid
Leakage exists when Financial Truth exceeds Commercial or Operational Truth 
LeakSight v1 - PRD
.
The system must always:
Be deterministic
Be explainable
Produce audit-grade proof
Never guess missing financial values
Never make pricing assumptions
